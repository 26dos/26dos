### About

I work on practical data and ML systems: pulling noisy signals from fragmented 
sources, shaping them into queryable datasets, and building evaluation loops
that make model behavior easier to inspect.

Most of my public work sits in domains where the data is awkward: transaction
streams, retrieval networks, industrial telemetry, and tool-using agents. The
domain changes; the engineering pattern is consistent: ingestion, validation,
feature extraction, structured storage, and reproducible evaluation.

### Currently

- Building labeled datasets and classifiers from high-volume event streams
- Designing LLM agent evaluation harnesses with structured outputs and scoring
- Developing evaluation harnesses that gate prompt and model changes
- Translating production-ish systems into reusable research and engineering artifacts


### Open to

Collaborations on:

- ML/NLP evaluation systems and agent observability
- dataset construction, feature engineering, and offline analysis pipelines
- retrieval, telemetry, and real-time ingestion infrastructure
